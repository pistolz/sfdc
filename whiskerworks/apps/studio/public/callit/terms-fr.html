  • Vous pouvez jouer sans compte. Si vous choisissez de vous connecter avec Apple ou Google (Réglages › Compte et sauvegarde), votre progression Call It est aussi sauvegardée dans le cloud et peut être restaurée sur un autre appareil. Synchroniser l'envoie tout de suite ; Se déconnecter arrête la synchronisation sans rien supprimer.
  • Le compte est un compte WhiskerWorks commun aux jeux WhiskerWorks qui en proposent un ; chaque jeu garde sa propre sauvegarde cloud, séparée. Si une sauvegarde existe à la fois sur cet iPhone et dans le cloud, le Jeu vous demande quelle progression garder ; l'autre est remplacée.
  • Vous pouvez supprimer votre compte à tout moment dans Réglages › Compte et sauvegarde › Supprimer le compte (il faudra vous reconnecter une fois pour confirmer). Cela supprime le compte commun aux jeux WhiskerWorks et leurs sauvegardes cloud ; votre progression reste sur votre appareil. Vous pouvez aussi nous le demander à bonjour@tazgo.ca.
